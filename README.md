## Что внутри

- статическая страница со списком репетиторов;
- фильтрация по языку программирования;
- тесты на встроенном тестовом раннере Node.js;
- линтер ESLint;
- CI/CD на GitHub Actions;
- автоматический деплой на GitHub Pages при пуше в `main`.

## Локальные команды

```bash
npm install
npm run lint
npm test
